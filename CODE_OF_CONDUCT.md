# Code of conduct

Watch the Goal follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep feedback about the work. No
harassment, insults or personal attacks, in issues, pull requests or anywhere
else the project gathers.

Please report unacceptable behaviour privately to the maintainer through
[GitHub](https://github.com/faizm10). Reports are kept confidential.
